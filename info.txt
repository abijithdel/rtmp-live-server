How to run the code 
setp 1 -> create 'media' and 'public/uploads/images' folder for the root folder
setp 2 -> Create Table; 
CREATE TABLE livestream (
    id SERIAL PRIMARY KEY,
    thumbnail VARCHAR(255),
    title VARCHAR(255),
    description VARCHAR(255),
    status VARCHAR(50),
    endview INT,
    streamkey VARCHAR(255)
);
setp 3 -> run npm start if dev(npm run dev)
